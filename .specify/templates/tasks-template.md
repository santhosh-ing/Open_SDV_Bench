# Task Breakdown Template

## Phase 1: Contract and design

- [ ] Define or update the DBC and diagnostic contract.
- [ ] Confirm interfaces with stakeholders or design owners.

## Phase 2: MCU and BSP

- [ ] Configure pins and peripherals.
- [ ] Implement board support modules.

## Phase 3: COM and diagnostics

- [ ] Add message packing and receive handling.
- [ ] Implement the required diagnostic service flow.

## Phase 4: Functional logic

- [ ] Implement feature state machines and outputs.
- [ ] Verify edge-case behavior.

## Phase 5: Validation

- [ ] Run project-specific verification steps.
- [ ] Capture results and follow-up actions.
