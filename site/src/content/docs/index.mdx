## The bench

A central vehicle computer and two zone controllers, an ADAS domain and a cloud tier — one small but realistic E/E architecture that mixes CAN and Ethernet.

<Topology />

## Why it is built this way

<CardGrid>
  <Card title="Architecture first" icon="puzzle">
    Logical, software, network and deployment views, and one decision record per choice — before the code that implements them.
  </Card>
  <Card title="Every function is traced" icon="list-format">
    Stakeholder need → system → function → component requirement → firmware → test, checked in CI on every change.
  </Card>
  <Card title="Real hardware, real buses" icon="setting">
    STM32 on CAN, Arduino and Jetson on Ethernet, Eclipse Kuksa, OpenSOVD and Ankaios on a Raspberry Pi 5 — with a virtual twin for each ECU.
  </Card>
</CardGrid>
